# Engineering workflow skills

This repository versions the skills and support documents for my engineering workflow.

The workflow is organized into phases. Each skill guides one phase and records its output so work can continue in a later session.

## Current contents

The repository includes these workflow skills and their support documents:

- [`clarify`](workflow/clarify/SKILL.md) investigates a proposed change and records decisions and open questions in a draft spec.
- [`promote-decisions`](workflow/promote-decisions/SKILL.md) moves eligible domain context and architectural decision candidates from a specified feature spec into their authoritative documents. This optional phase requires an explicit spec path and runs before ticketing or implementation.

More workflow skills will be added over time.

## Use

Copy the relevant skill directory under `.agents/skills/` and its required support documents into the project. Follow the skill’s instructions and the project-specific conventions in those documents.
