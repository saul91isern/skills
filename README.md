# Engineering workflow skills

This repository versions the skills and support documents for my engineering workflow.

The workflow is organized into phases. Each skill guides one phase and records its output so work can continue in a later session.

## Current contents

The repository currently includes the `clarify` skill and the support documents it needs. More workflow skills will be added over time.

## Use

Copy the relevant skill directory under `.agents/skills/` and its required support documents into the project. Follow the skill’s instructions and the project-specific conventions in those documents.
